# 📱 QR Code Generator

A simple and customizable QR code generator built using Python. Supports encoding URLs, text, or any data into scannable QR codes. Easily export your QR codes as PNG images.

---

## ✨ Features

- Generate QR codes from text or URLs
- Customize size, color, and border
- Save QR codes as image files (PNG, JPG)

---

## 🛠️ Built With

- [Python](https://www.python.org/)
- [qrcode](https://pypi.org/project/qrcode/)
- [Pillow](https://pypi.org/project/Pillow/)
